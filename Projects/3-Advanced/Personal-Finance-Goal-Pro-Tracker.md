# Personal Finance Goal Pro Tracker

**Tier:** 3-Advanced

Track your financial goals including savings, investments, and debt payoff. This app helps users log transactions, visualize progress, and stay on track with their financial planning.

* This application will help users manage their finances by tracking goals, transactions, and generating progress reports
* Resource needed for the project is a backend server, database, and optional finance APIs for automatic transaction tracking

## User Stories

* [ ] User can create an account and log in securely
* [ ] User can set multiple financial goals (savings, investments, debt payoff)
* [ ] User can log and categorize transactions (income, expense, investment)
* [ ] User can view progress towards each goal with visual charts
* [ ] User can edit or delete goals and transactions
* [ ] User can see monthly, quarterly, or yearly financial summaries
* [ ] User can get forecasts on when goals will be achieved based on current trends

## Bonus features

* [ ] User can link bank accounts to automatically track transactions
* [ ] User can set recurring income or expenses for better forecasting
* [ ] User can receive personalized tips to save more or pay off debt faster
* [ ] User can export financial data as CSV or PDF
* [ ] User can compare multiple financial scenarios to optimize savings or investments
* [ ] User can enable dark mode for better UX
