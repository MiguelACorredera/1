# Music Streaming Platform

**Tier:** 3-Advanced

Allow users to upload, play, and organize music playlists, with options for live audio streaming.

## User Stories

- [ ] User can create an account and log in.  
- [ ] User can upload audio files and provide metadata (title, artist, album, cover image).  
- [ ] User can play, pause, skip, and rewind tracks.  
- [ ] User can create, edit, and delete playlists.  
- [ ] Users can browse music by categories, genres, or popularity.  

## Bonus Features

- [ ] Real-time streaming of audio tracks.  
- [ ] Allow users to like and comment on tracks.  
- [ ] Implement search functionality for songs, artists, and albums.  
- [ ] Enable recommendations based on user listening history.  
- [ ] Offline mode for cached songs.  

## Useful Links and Resources

- [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) for audio playback and processing  
- [React](https://reactjs.org) for building interactive UI  
- [Node.js](https://nodejs.org) and [Express.js](https://expressjs.com) for backend APIs  
- [MongoDB](https://www.mongodb.com) for storing user data and playlists  
- [Firebase](https://firebase.google.com) for authentication and real-time features
