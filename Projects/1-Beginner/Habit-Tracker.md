# Habit Tracker

**Tier:** 1-Beginner

A simple application to help users track and build good habits over time. Users can add daily habits, mark them as completed, and view progress in a calendar or list format.

- **Purpose:** The app motivates users to maintain consistency and visualize their progress.

- **Resources needed:** None — can be built using basic HTML/CSS/JS or any beginner-friendly framework.

## User Stories

- [ ] User can create a new habit with a name and optional description
- [ ] User can mark a habit as completed for the day
- [ ] User can view a list of all habits
- [ ] User can see a weekly or monthly progress summary
- [ ] User can delete or edit existing habits

## Bonus features

- [ ] User can set reminders or notifications for habits
- [ ] User can visualize progress with charts or streak counters
- [ ] User can categorize habits (e.g., Health, Study, Fitness)
- [ ] User can export or save habit data to a file or cloud
