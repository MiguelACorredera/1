# Dec2Bin

**Tier:** 1-Beginner

Binary is the number system all digital computers are based on.
Therefore it's important for developers to understand binary numbers, or base 2 mathematics. 
The purpose of Dec2Bin is to provide practice and understanding of how binary calculations work.

Dec2Bin allows the user to enter integers and displays its binary equivalent

This challenge requires that the developer implementing it follow these constraints:

-  Only integer datatype is allowed as the input.
-  The binary output of the integer must be a string.

## User Stories

-   [ ] User can enter any integer.
-   [ ] User must be notified if 0 or 1 was entered as a part of validation error.
-   [ ] User views the results in a single output field containing the binary (base 2) equivalent of the decimal that was entered
