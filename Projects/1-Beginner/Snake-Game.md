# Snake Game
**Tier:** 1-Beginner

## Description
A classic Snake game implementation using Python's Turtle graphics library. Control a snake to eat food and grow longer while avoiding walls and your own tail!

## Purpose
To create a fun, interactive Python game that helps beginners practice programming, logic, and working with Python’s Turtle library.

## Resources Needed
- Python 3.x  
- Turtle graphics library (built-in with Python)  

## User Stories
- [ ] User can control the snake using WASD or arrow keys.  
- [ ] User can eat food to grow the snake.  
- [ ] User can see and track their current score.  
- [ ] Game ends when the snake collides with walls or itself.  
- [ ] Game displays the snake, food, and score clearly on the screen.  

## Bonus Features
- [ ] Implement increasing speed as the snake grows.  
- [ ] Add sound effects for eating food or game over.  
- [ ] Allow the player to restart the game without closing it.  
- [ ] Add multiple difficulty levels (e.g., easy, medium, hard).
