# Bin2Dec  
**Tier:** 1-Beginner  

Binary is the number system that all digital computers are based on. Therefore, it's important for developers to understand binary (base-2) mathematics. The purpose of **Bin2Dec** is to help users practice and understand how binary calculations work.  

**Bin2Dec** allows the user to enter strings of up to 8 binary digits (0s and 1s) in any sequence and then displays their decimal equivalent.  

---

## Requirements  
This challenge requires that the developer implementing it follows these constraints:  

- Arrays may **not** be used to contain the binary digits entered by the user.  
- Determining the decimal equivalent of a particular binary digit in the sequence must be calculated using a single mathematical function (for example, the natural logarithm). It’s up to you to determine which function to use.  

---

## User Stories  
- User can enter up to 8 binary digits in one input field.  
- User must be notified if anything other than a 0 or 1 is entered.  
- User can view the result in a single output field containing the decimal (base-10) equivalent of the entered binary number.  

---

## Bonus Features  
- User can enter a variable number of binary digits.
