# AI Bug Reporter

**Tier:** 1-Beginner

## Objective
Build a widget that captures screenshots, voice recordings, console errors, and uses AI to triage bug severity.

## User Stories
- User can click a button to report a bug
- Screenshot is auto-captured
- Console errors are logged
- AI determines severity
