# Expense Tracker App

A simple web application to track daily expenses and manage personal finances.

## User Stories
- [ ] User can add new expenses with description, amount, and category
- [ ] User can view all expenses in a list with total amount
- [ ] User can delete expenses from the list
- [ ] User can filter expenses by category

## Bonus Features
- [ ] User can edit existing expenses
- [ ] User can see spending statistics with charts
- [ ] Data persists using localStorage
- [ ] User can export expenses to CSV

## Technologies
- HTML, CSS, JavaScript
- Local Storage for data persistence
- Chart.js for statistics (optional)

## Implementation Tips
- Start with basic CRUD operations
- Use arrays and objects to manage expense data
- Implement localStorage for data persistence
- Add input validation for amount fields

## Learning Outcomes
- DOM manipulation
- Array methods (filter, map, reduce)
- Local Storage API
- Event handling
