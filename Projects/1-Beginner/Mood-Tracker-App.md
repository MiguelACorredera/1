# Mood Tracker 🧠

**Tier:** 1-Beginner

## Objective  
Build a simple app for users to log their daily mood (from predefined mood options) along with optional notes, and to review their mood history visually over time.

## User Stories  
1. As a user, I want to add a mood entry for “today” (choose mood + optional note).  
2. As a user, I want to view a list of all my past mood entries.  
3. As a user, I want to edit or delete a mood entry in case of mistakes.  
4. As a user, I want to view full details of a mood entry (mood, note, timestamp).  
5. As a user, I want to filter or search mood entries (e.g. by mood type or keyword).  
6. As a user, I want to see a simple visual summary (chart) of mood trends over time.  
7. As a user, I want my data to persist so I can reopen the app and see prior entries.

## Bonus Features (Optional)  
- Support tags (e.g. “Work”, “Health”) and filter by tags  
- Daily reminders / notifications to log mood  
- Export mood history (CSV, JSON)  
- Backup / sync with a simple backend or cloud  
- Advanced visualizations (e.g. moving average, streak tracking)  
- Settings screen (add / remove moods, change theme)  
- Dark mode / theming  
- User authentication (login / signup)  
- Localization (multi-language support)
