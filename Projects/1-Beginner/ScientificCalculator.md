

# 🧮 Scientific Calculator

**Tier:** 1-Beginner

A modern **Scientific Calculator** built using **HTML, CSS, and JavaScript** — without using the `eval()` function.  
It supports both **basic arithmetic** and **advanced scientific operations** like trigonometric, logarithmic, and exponential functions.

You can try it live here 👉 [Scientific Calculator on CodePen](https://codepen.io/Ilmakramansari/pen/bNErvKX)

---

## 🎯 Features / User Stories

- [ ] User can see a display showing the current number entered or the result of the last operation.  
- [ ] User can perform **basic operations** — addition (+), subtraction (-), multiplication (×), and division (÷).  
- [ ] User can perform **scientific functions** including:
  - sin, cos, tan (toggle between degree/radian)
  - log, ln (natural log)
  - √ (square root)
  - x², x³, xʸ (power)
  - exp, π, e
  - 1/x, %, abs
- [ ] User can toggle between **Radian** and **Degree** mode for trigonometric functions.  
- [ ] User can use **C** (clear) and **AC** (clear all) buttons.  
- [ ] User can see an error message (`ERR`) for invalid operations.  
- [ ] User can interact through an intuitive and responsive UI designed with modern styling.
