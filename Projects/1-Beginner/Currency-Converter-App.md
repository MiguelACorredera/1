# Currency Converter App

A web application that converts between different currencies using real-time exchange rates.

## Objective
Build an application that can convert amounts between different currencies with up-to-date exchange rates.

## User Stories
- [ ] User can see a dropdown list of available currencies
- [ ] User can select a source currency and target currency
- [ ] User can enter an amount to convert
- [ ] User can see the converted amount in real-time
- [ ] User can see the current exchange rate
- [ ] User can swap source and target currencies with a button

## Bonus Features
- [ ] User can see a history of exchange rates
- [ ] User can favorite frequently used currencies
- [ ] User can see currency flags alongside names
- [ ] User can convert to multiple currencies at once
- [ ] Application works offline with cached rates

## Technologies
- HTML, CSS, JavaScript
- Free Currency API: [exchangerate-api.com](https://www.exchangerate-api.com)
- Local Storage for favorites

## Difficulty
- **Beginner Level** - Basic JavaScript and API calls

## Example APIs
- Free Tier: [ExchangeRate-API](https://www.exchangerate-api.com)
- Alternative: [Frankfurter API](https://www.frankfurter.app)

## Learning Concepts
- API Integration
- Asynchronous JavaScript
- DOM Manipulation
- Error Handling
- Local Storage
