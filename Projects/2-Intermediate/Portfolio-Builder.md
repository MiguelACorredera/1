# Portfolio Builder

**Tier:** 2-Intermediate

Allow users to create and showcase their personal portfolios dynamically.

## User Stories

- [ ] User can add personal information (name, bio, contact info).  
- [ ] User can add multiple projects with descriptions, images, and links.  
- [ ] User can preview the portfolio in a real-time view.  
- [ ] User can edit or delete any section of their portfolio.  

## Bonus Features

- [ ] Store portfolio data in a database so that it can be accessed later.  
- [ ] Allow users to choose from multiple themes or templates for their portfolio.  
- [ ] Enable sharing portfolio via a public link.  
- [ ] Implement authentication so that only the user can edit their portfolio.  

## Useful Links and Resources

- [Firebase](https://firebase.google.com) for realtime database and authentication  
- [React](https://reactjs.org) for building dynamic UI  
- [Tailwind CSS](https://tailwindcss.com) for styling
