# Habit Tracker

**Tier:** 2-Intermediate

Habit Tracker is an app designed to help users build and maintain positive habits by tracking daily progress, visualizing streaks, and sending reminders. Users can create, edit, and manage habits, mark them as completed, and view their progress over time. To implement this project, a database or local storage is needed for storing habit data, along with a charting library (e.g., Chart.js or Recharts) for visualizing streaks. Notifications or cron jobs can be added to provide daily reminders.

## User Stories

-   [ ] User can create, edit, and delete habits
-   [ ] User can mark a habit as completed for the day
-   [ ] User can view a dashboard of their daily/weekly progress
-   [ ] User can see streaks for each habit
-   [ ] User can set daily reminders/notifications for each habit

## Bonus features

-   [ ] User can categorize habits (e.g., health, learning, productivity)
-   [ ] User can view charts of success rates and streaks
-   [ ] User can earn badges/achievements for milestones
-   [ ] User can export their habit data as CSV/JSON
-   [ ] User can share progress with friends for accountability
